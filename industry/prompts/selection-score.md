## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认"谁，在什么时候，做了什么，处于宣布、发布、中标、扩产还是复盘阶段"。然后从以下 6 类中选择最贴近的一类：

- `product_launch`：真空泵、机组、阀门、测量仪器、检漏设备、配件的新品发布或重大型号更新
- `price_market`：泵价波动、原材料行情、招投标中标价格、市场供需变化
- `tech_repair`：选型方法、维修保养实践、故障诊断、真空工艺应用（镀膜/半导体/光伏/冻干等）
- `industry_event`：扩产建厂、并购合作、人事、经营数据、行业格局变化
- `policy_standard`：国标行标发布修订、能效与环保政策、出口管制、认证要求
- `expo_activity`：展会、行业会议、厂商开放日、线上研讨会

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在真空行业时间线上是节点、这周值得知道的变化，还是当天脚注。不要把"能马上用"重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。具体新机型、新参数、新价格、新产能、新标准条款才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方公告足以证明"发布、扩产、中标"这一动作，但不能自动证明宣传中的效果；行情类材料有具体数据来源才算强证据。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关——采购的人、卖设备的人、修设备的人、关注行业格局的人。
5. `act` 可用性：读者是否能马上使用、学习、调整采购或维修做法。纯新闻和重大事件的 act 低是正常的，不应反过来抹掉 sig。

## 品味规则

### 必须正常评价的价值

- 头部厂商（普旭、莱宝、爱德华、普发、阿特拉斯等）与国产主力（中科仪、北方华创、汉钟、鲍斯等）的正式新品发布：新泵型、新系列、明确的性能参数或应用边界变化。
- 国产替代的实质进展：国产分子泵/干泵在半导体产线的验证通过、批量出货、产能落地——这是当前行业最重要的主线之一。
- 明确的价格与行情变化：涨价函、原材料对泵价的传导、大额招投标中标价格，有具体数字与来源的按真实份量评分。
- 标准与政策的落地：真空设备国标/行标发布与修订、能效等级要求、出口管制清单变化——直接影响生意，`sig` 按影响面给。
- 扩产建厂与并购：产能变化是行业景气的先行信号，按规模正常评价。
- 大型真空展会（真空博览会等）的开幕、厂商集中发布——按展会的行业信号意义评分。
- 可立即复用的选型/维修知识：具体故障的诊断方法、保养周期口径、按工况选泵的对比——对维修工程师真实有用，即使不是行业大事也可以很高。

### 必须压住的噪声

- 无实质参数的产品宣传稿、"某工厂用了某泵"的 PR，若没有明确工况、规模、成本或可迁移方法，`sig ≤ 4`。
- 常规型号小改款、配色/外观升级、单纯渠道活动，`sig ≤ 3`。
- 门店开业、赞助、招聘、年会、限免、模糊预告，`sig ≤ 2`；只有"即将推出"没有参数，`nov ≤ 3` 且 `cred ≤ 4`。
- 单一小额中标（无行业信号意义）、社区团购类信息，`sig ≤ 3`。
- 内容农场式行情文：只说"涨价了"没有数据、来源或具体型号价格，`cred ≤ 3`。
- 科普陈词滥调（"什么是真空泵""真空泵原理"这种通用百科复读），`sig ≤ 2`；但针对具体故障或具体工况的实操内容不算。
- 家用真空吸尘器、食品真空袋（家用）等与真空设备行业无关的消费品的新闻，`sig ≤ 1`。
- 新闻摘要合集、多事件打包且没有单一焦点，`sig ≤ 3`。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认"有人声称某事"，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给"这篇文章写得怎么样"打分。
2. 价格与行情类材料：一次有数据、有范围、有官方来源的涨价（如"某系列泵价上调 5–8%，因硅钢片涨价"）是真实事件，`sig` 按波及面给；不要因为它是"价格信息"而机械低分。
3. 国产替代类材料：验证通过、批量出货、产线落地是强事件；只在发布会上"宣布布局"而无出货与验证事实，按较弱主张给 `cred`。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如"新品发布 + 一句客户案例"，不能只抓住案例身份。
5. 反过来，长篇、完整、数字很多，仍不能替一个不成立的因果、厂商营销或宏大推断制造事件价值。只有正文支持的新事实、可用性变化或可迁移方法进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
