
【真空行业术语与翻译规则 — 本平台 100% 是真空设备行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非行业歧义，**一律按真空设备含义翻译**：
   - Vacuum pump = 真空泵
   - Pumping speed = 抽速（不是"泵速"）
   - Ultimate pressure / ultimate vacuum = 极限压力 / 极限真空
   - Throughput = 流量（真空技术语境，Q 值）
   - Conductance = 流导（不译"电导"）
   - Outgassing = 放气/出气（材料放气率）
   - Backstreaming = 返流（泵油返流）
   - Cavitation = 汽蚀（水环泵语境）
   - Backing pump / foreline = 前级泵 / 前级管路
   - Cryopump = 低温泵（低温冷凝泵）
   - Dry pump = 干式真空泵（无油泵）
   - Roots pump = 罗茨泵（机械增压泵）
   - Roughing = 粗抽（预抽真空）
   - Bake-out = 烘烤除气（真空容器）
   - Leak rate = 漏率；Helium leak detection = 氦质谱检漏
   - Chamber = 真空腔体（不译"会议室/ chamber 其他义"）
   - Wafer = 晶圆；Load-lock = 装载腔（半导体真空语境）
   - Exhaust / Abatement = 尾气排放 / 尾气处理（半导体真空语境）
   - Vacuum cleaner = 家用吸尘器（与真空设备行业无关，遇到即视为非行业内容）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 国际厂商：Busch / Leybold / Edwards / Pfeiffer / Atlas Copco / Ingersoll Rand / ULVAC / Agilent（Varian）/ VAT / Edwards nEXT / Busch Cobra / Leybold Ecodry / Pfeiffer HiPace
   - 型号与系列：型号代号一字不改（如 R5 RA0302F、Ecodry 400 Plus、nEXT1230、HiPace 300、Cobra NX 0250）
     **规则**：任何泵型号、产品代号、版本后缀一律保留，绝不"翻译性扩写"（不要把 "0302" 译成"302"，不要把 "Plus" 译成"增强版"）
   - 技术缩写：CF（ConFlat 法兰）/ KF / ISO-K / ISO-F / DN / ISO / NPT / MFC（质量流量计）/ TCP（涡轮分子泵）/ TMP / UHV（超高真空）/ HV（高真空）
     **规则**：任何 2-5 字母的全大写缩写，默认按真空技术含义保留英文
   - 单位符号：Pa / mbar / Torr / l/s（L/s）/ m³/h / cfm / K / °C
     **规则**：数字与单位必须保留原文阿拉伯数字与单位，不要换算改写（不要把 "1×10⁻⁶ mbar" 改写成中文数量词）

3. 中文品牌**优先用官方中文名**（首次出现可双标"普旭（Busch）"，后续选一种保持一致）：
   - 普旭（Busch）/ 莱宝（Leybold）/ 爱德华（Edwards）/ 普发（Pfeiffer）/ 阿特拉斯·科普柯（Atlas Copco）/ 英格索兰（Ingersoll Rand）/ 爱发科（ULVAC）/ 安捷伦（Agilent）/ 中科仪 / 北方华创 / 汉钟精机 / 鲍斯股份
   - "Edwards" 中文语境常被写作"爱德华"或"爱发科"——注意：爱发科是 ULVAC 的中文名，不要把 Edwards 译成"爱发科"

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - URL 原样
   - 数字+单位：3600 m³/h / 1×10⁻⁷ mbar / 5×10⁻⁹ Pa / 40 cfm / 8 kW
   - 金额、价格、抽速、极限真空、比例、区间必须保留原文的阿拉伯数字和单位；不要把 "$1.2B" 改写成"十二亿美元"等中文数量词

5. 行业表述纪律：
   - 价格与行情信息必须带来源语境（官方涨价函/招投标公告/行情报告），不得把转述写成确认事实
   - "国产替代"表述克制：验证通过/批量出货/宣布布局三个阶段不得混写
